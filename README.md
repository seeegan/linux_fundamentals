# Linux fundamentals

Так как почти любая технология в нынешем backend работает на сервере который имеет ядро Linux и определенный дистрибутив, нам необходимо разбираться как он работает "под капотом". Без такой "базы" мы не сможем понять или заиметь "контекст" в какой-то из изучаемых технологий. Поэтому будем изучать все прям с полного нуля, желательно конечно подкреплять это все практикой.

Вдаваться в подробности как Linux создавался я не хочу, да и наверное оно не нужно, тут больше техническая теория которая будет необходима для понимания как работает та или иная технология на сервере Linux.
